HOW TO USE

  1. Click a circle to set it as the active node (start point)
  2. Click another circle to set it as the target node
  3. Up to 4 tangent lines appear between the two circles
  4. Click a tangent line to add it to the contour
  5. The target becomes the new active node — repeat
  6. Return to the starting circle to close the contour

Press Esc to cancel selection · Press ? to toggle help
